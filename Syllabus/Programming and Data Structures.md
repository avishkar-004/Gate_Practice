# Programming and Data Structures — GATE CSE

## Official GATE 2027 syllabus

The official GATE CS syllabus lists these topics under **Programming and Data Structures**:

- Programming in C
- Recursion
- Arrays, stacks and queues
- Linked lists
- Trees and binary search trees
- Binary heaps
- Graphs

> Sorting, searching, hashing, asymptotic complexity, and graph algorithm topics are listed separately in the official **Algorithms** section. They are useful prerequisites and related study, but are not listed here as Programming and Data Structures topics.

## Topics to study

### 1. C programming

- Data types, variables, constants and type conversion
- Operators, expressions, precedence and associativity
- Conditional statements and loops
- Functions, prototypes, arguments, return values and scope
- Parameter passing and function calls
- Pointers, pointer arithmetic and pointers to pointers
- Arrays, strings and the relationship between arrays and pointers
- Structures, unions, enumerations and `typedef`
- Dynamic memory allocation: `malloc`, `calloc`, `realloc` and `free`
- Tracing C code, including function calls, side effects and return values

### 2. Recursion

- Base cases and recursive cases
- Tracing recursive calls and return values
- Recursion on arrays, strings, linked lists and trees
- Common examples: factorial, Fibonacci, binary search and tree traversals
- The recursion call stack and auxiliary space
- Converting simple recursive procedures to iterative procedures

### 3. Arrays

- One-dimensional and multidimensional arrays
- Indexing and address calculation
- Traversal, insertion and deletion
- Array-based representations of data structures
- Two-dimensional array layout and access
- Strings as character arrays and null termination

### 4. Linked lists

- Singly linked lists
- Doubly linked lists
- Circular linked lists
- Traversal and searching
- Insertion and deletion at different positions
- Reversing a linked list
- Slow and fast pointer techniques
- Array versus linked-list representations

### 5. Stacks and queues

- Stack operations: push, pop and peek/top
- Queue operations: enqueue and dequeue
- Array-based and linked-list implementations
- Circular queues
- Deques and priority queues
- Applications: function-call stack, parentheses matching, and expression conversion or evaluation

### 6. Trees

- Tree terminology and basic properties
- Binary trees and common representations
- Preorder, inorder, postorder and level-order traversals
- Tree height, depth, leaves and node counts
- Binary search tree property
- Searching, insertion and deletion in binary search trees
- Constructing or identifying trees from traversal orders

### 7. Binary heaps

- Min-heaps and max-heaps
- Array representation of a heap
- Parent and child index calculations
- Insertion and deletion of the root
- Heapify operations
- Building a heap from an array

### 8. Graphs

- Graph terminology and properties
- Directed, undirected and weighted graphs
- Adjacency matrix and adjacency list representations
- Breadth-first search (BFS)
- Depth-first search (DFS)
- Tracing graph traversals and understanding their costs
- Connected components and basic graph properties

## Recommended study order

1. C fundamentals
2. Pointers and arrays
3. Recursion
4. Linked lists
5. Stacks and queues
6. Trees, binary search trees and heaps
7. Graph representations, BFS and DFS

## Practice checklist

- Trace short C programs carefully, especially those involving pointers, arrays and recursion.
- Perform each data-structure operation by hand and track how the representation changes.
- Be able to choose an appropriate representation for a given operation or problem.
- Analyze the time and auxiliary space used by basic operations.
- Practice GATE previous-year questions after completing each topic.
