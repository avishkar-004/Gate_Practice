# Algorithms — GATE CSE

## Official GATE 2027 syllabus

The official GATE CS syllabus lists these topics under **Algorithms**:

- Searching, sorting and hashing
- Asymptotic worst-case time and space complexity
- Algorithm design techniques: greedy, dynamic programming and divide-and-conquer
- Graph traversals, minimum spanning trees and shortest paths

## Topics to study

The following study outline expands those syllabus headings into the concepts and problem-solving skills to practice.

### 1. Asymptotic analysis

- Worst-case time and space complexity
- Big-O, Big-Ω and Big-Θ notation
- Comparing growth rates and simplifying asymptotic expressions
- Analyzing loops and nested loops
- Analyzing recursive algorithms using recurrences and recursion trees
- Auxiliary space, including recursion stack space
- Best, average and worst case where relevant; prioritize worst-case analysis per the syllabus

### 2. Searching

- Linear search and binary search
- Preconditions for binary search
- Iterative and recursive binary search
- Number of comparisons and boundary cases
- Search in sorted arrays and answer-space binary search

### 3. Sorting

- Insertion sort, selection sort and bubble sort
- Merge sort and quicksort
- Heap sort
- Counting sort and radix sort
- Best, average and worst-case time and auxiliary space
- Stable versus unstable sorting
- In-place versus out-of-place sorting
- Partitioning and recurrence analysis for sorting algorithms

### 4. Hashing

- Hash functions and hash tables
- Collision handling: chaining and open addressing
- Linear probing, quadratic probing and double hashing
- Load factor and its effect on performance
- Insert, search and delete operations
- Clustering and probe sequences
- Expected versus worst-case behavior

### 5. Divide-and-conquer

- Identifying subproblems, combining results and base cases
- Recurrence formulation and solution
- Recursion-tree analysis and Master Theorem
- Merge sort and binary search
- Quicksort and partitioning
- Other recurrence-based algorithm analysis

### 6. Greedy algorithms

- Greedy-choice property and optimal substructure
- Proving or disproving a greedy strategy
- Activity selection
- Fractional knapsack
- Huffman coding
- Minimum spanning tree algorithms
- Scheduling and ordering problems

### 7. Dynamic programming

- Optimal substructure and overlapping subproblems
- Defining states and recurrence relations
- Memoization and tabulation
- Reconstructing an optimal solution
- 0/1 knapsack
- Longest common subsequence
- Matrix-chain multiplication
- Coin change and related recurrence problems

### 8. Graph algorithms

- Breadth-first search (BFS) and depth-first search (DFS)
- Traversal order, connected components and complexity
- Minimum spanning trees: Prim's and Kruskal's algorithms
- Shortest paths: Dijkstra's and Bellman–Ford algorithms
- Floyd–Warshall all-pairs shortest paths
- Relaxation, negative edge weights and negative cycles
- Choosing an algorithm based on graph properties

## Recommended study order

1. Asymptotic analysis and recurrences
2. Searching and sorting
3. Hashing
4. Divide-and-conquer
5. Greedy algorithms
6. Dynamic programming
7. Graph traversals, minimum spanning trees and shortest paths
