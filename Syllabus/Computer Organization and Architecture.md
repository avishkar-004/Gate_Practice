# Computer Organization and Architecture — GATE CSE

## Official GATE 2027 syllabus

The official GATE CS syllabus lists these topics under **Computer Organization and Architecture**:

- Instruction set and addressing modes
- Design of the arithmetic and logic unit (ALU)
- Design of the control unit: hardwired and microprogrammed
- Memory interfacing and hierarchy: performance and cache memory mapping
- I/O interface: interrupts and direct memory access (DMA)
- Instruction pipelining and pipeline hazards

## Topics to study

### 1. Instruction set and addressing modes

- Instruction formats and instruction fields
- Register, memory and immediate operands
- Common instruction classes and their effects
- Effective-address calculation for common addressing modes
- Instruction length and number of addressable locations
- Instruction execution steps and register-transfer interpretation

### 2. Arithmetic and logic unit (ALU)

- ALU functions and control inputs
- Addition, subtraction and arithmetic operations
- Two's-complement arithmetic and overflow detection
- Comparators and basic logic operations
- Shifters and arithmetic versus logical shifts
- Selecting ALU operations from control signals

### 3. Control unit

- Control signals and instruction sequencing
- Hardwired control: control logic and state sequencing
- Microprogrammed control: control store and microinstructions
- Microinstruction fields and control-word interpretation
- Comparing hardwired and microprogrammed control

### 4. Memory interfacing and hierarchy

- Memory organization, address lines and data lines
- Address decoding and memory-chip interfacing
- Capacity calculations from address and data widths
- Memory hierarchy and locality
- Cache terminology: blocks, lines, tags, index and offset
- Direct-mapped, fully associative and set-associative caches
- Cache address breakdown and mapping
- Cache hits, misses, hit ratio and miss penalty
- Average memory access time and basic performance comparisons

### 5. I/O interface

- I/O interface registers and device communication
- Programmed I/O and interrupt-driven I/O concepts
- Interrupt requests, service routines and interrupt handling sequence
- Interrupt priority and vectored interrupts
- DMA operation and its interaction with the CPU and memory
- Transfer-time and data-rate calculations for I/O operations

### 6. Instruction pipelining and hazards

- Pipeline stages and instruction overlap
- Pipeline timing diagrams
- Pipeline throughput, latency and speedup
- Structural, data and control hazards
- Stalls, forwarding and branch penalties
- Pipeline performance with unequal stage times and hazard penalties

## Recommended study order

1. Instruction formats, execution and addressing modes
2. ALU arithmetic and control signals
3. Hardwired and microprogrammed control
4. Memory interfacing, cache mapping and performance
5. Interrupts and DMA
6. Pipeline timing and hazards
